- 等宽字体 13px
- 日志级别用语义色:DEBUG/INFO/WARN/ERROR
- 最多保留 200 条,自动滚动到底部
- 暂停按钮:点击停止自动滚动,允许向上翻阅
- 顶栏:级别筛选(全部/INFO/WARN/ERROR)+ 清空 + 导出

### 3.5 数字人入口(决策 2 = D:单独模式)

桌面/平板/手机都通过**顶部 Tab 切换**进入"数字人模式":

```
顶部 Tab: [数据模式]  [● 数字人模式]
                            ↑
                       暖橙活跃态
```

数字人模式 = 全屏复用 `digital-human/index.html`:
- 背景 Live2D 居中
- 底部输入框(支持文本/语音)
- 左侧对话历史(可隐藏)
- 右侧工具按钮(MCP 工具、调用链)

手机端进入数字人模式后,自动全屏沉浸(隐藏 Tab Bar 和顶栏)。

手机:**第一行筛选 + 展开更多**,或底部 Sheet 收纳

### 14.5 加载 / 空 / 错误状态

- 加载:骨架屏(skeleton,浅灰块)或 spinner
- 空:大图标(Lucide 64px) + 文字 + 主操作按钮
- 错误:大图标(AlertCircle 64px,红) + 错误描述 + 重试按钮

三端一致,只是空/错误状态的插图大小不同(桌面 120px / Pad 96px / 手机 64px)。
